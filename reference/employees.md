# An employees dataset for demonstrating the functions in allin1

An employees dataset for demonstrating the functions in allin1

## Usage

``` r
employees
```

## Format

### `employees`

A data frame with 5 rows and 3 columns:

- name:

  A string denoting the name of employee

- hours_worked:

  Integer for hours worked

- hourly_wage:

  Integer for hourly_wage
